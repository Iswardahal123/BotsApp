## 2025-06-16 - [Command Scannability and Status Accuracy]
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Additionally, copy-paste errors in status messages (like reporting "True" for a "Disabled" state) can erode user trust.
**Action:** Always sort command lists alphabetically and include a total count for feedback. Carefully review status message templates for consistency when copying existing modules.
