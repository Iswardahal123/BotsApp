## 2025-05-14 - Alphabetical Command Sorting and Validated Feedback
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a total command count and correct prefix hints in the header offers immediate feedback on the bot's scale and usage.
**Action:** Always sort command lists alphabetically and provide a summary header (total count, prefix) for help menus. Ensure visual feedback (like reactions) only triggers after input validation.
