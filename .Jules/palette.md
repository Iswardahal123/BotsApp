## 2025-05-14 - [Dynamic Bot Interfaces]
**Learning:** Alphabetical sorting of command lists and dynamic prefix extraction significantly enhance scannability and reliability in chat-based interfaces. Providing immediate feedback on the bot's scale (total commands) improves user confidence.
**Action:** Always avoid hardcoding command prefixes in strings; extract them from the bot's configuration to ensure accurate feedback across all user settings. Sort command lists by default to aid visual search.
