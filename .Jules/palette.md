## 2026-06-20 - Alphabetical Scannability and Scale Feedback
**Learning:** In chat-based bot interfaces, alphabetical sorting of command lists significantly improves user scannability compared to arbitrary insertion order. Additionally, providing a total command count in the help header offers immediate feedback on the bot's scale and capabilities.
**Action:** Always sort command/feature lists alphabetically and provide quantitative feedback (like counts) in main navigation or help menus to enhance the user's mental model of the system.
