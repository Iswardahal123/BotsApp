## 2025-05-15 - [Alphabetical Sorting and Command Count]
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a total command count in the header offers immediate feedback on the bot's scale and helps users understand the breadth of available features.
**Action:** Always sort dynamic lists of options or commands alphabetically and provide summary statistics (like counts) in menus to improve user orientation.
