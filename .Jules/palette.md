## 2025-05-14 - [Alphabetical help menu and standardized feedback]
**Learning:** In chat-based interfaces, users primarily navigate via visual scanning. Alphabetical sorting of command lists significantly improves scannability. Furthermore, providing consistent and actionable feedback for invalid commands (e.g., suggesting the help command) reduces user friction.
**Action:** Always sort command menus by default and use centralized string templates for common bot responses to ensure UX consistency.
