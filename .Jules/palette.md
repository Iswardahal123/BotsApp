## 2025-05-14 - Scannability and Dynamic Feedback
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a total command count in the header offers immediate feedback on the bot's scale. Standardizing error messages with dynamic prefix detection prevents user confusion when the command prefix is customized.
**Action:** Always sort command lists alphabetically and use dynamic prefix extraction from configuration for all bot-generated instructions and feedback.
