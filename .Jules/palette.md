## 2025-05-14 - [Alphabetical Scannability in Chat Bots]
**Learning:** In chat-based interfaces, users primarily navigate command lists via visual search. Alphabetical sorting significantly reduces cognitive load and improves scannability compared to unsorted lists. Adding a total command count provides immediate feedback on the application's breadth and aids in navigation.
**Action:** Always default to alphabetical sorting for command or feature lists in bot interfaces and include summary metrics (like counts) in headers to provide scale and context.
