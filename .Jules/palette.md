## 2026-04-17 - [Scannability and Scale in Help Menus]
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a summary of available features (e.g., 'Total Commands: 42') gives users immediate context about the application's scale and capabilities.
**Action:** Always sort menus alphabetically by default and include high-level metrics in menu headers to improve user orientation.
