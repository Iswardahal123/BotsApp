## 2026-06-15 - Alphabetical Sorting and Command Counts in Help Menus
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a total command count in the header offers immediate feedback on the bot's scale and confirms all commands were loaded.
**Action:** When implementing help menus or command lists, default to alphabetical sorting and include summary metadata (like total counts) to enhance user orientation.
