## 2025-05-14 - [Alphabetical help menu]
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation.
**Action:** Always sort menus by default unless usage frequency warrants otherwise.

## 2025-05-14 - [Invalid command feedback]
**Learning:** Standardizing invalid command feedback with clear instructions (e.g., "Use .help") provides a better recovery path for users who make typos.
**Action:** Centralize error messages in a strings database and include actionable help triggers.
