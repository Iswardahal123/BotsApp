## 2026-03-27 - [Standardizing Help & Error UX]
**Learning:** UX improvements must be strictly additive or transformative without removing existing features, even if those features are currently 'broken' due to external factors (like unpublished dependencies). Disabling modules to pass CI/build checks is a functional regression.
**Action:** Focus on localized UX enhancements and avoid touching unrelated configuration or dependency files unless absolutely necessary for the UX change itself.
