## 2025-05-14 - [Alphabetical Help Menu]
**Learning:** Sorting long command lists alphabetically significantly improves discoverability for users scanning for features.
**Action:** Always sort dynamic lists of commands or options by name in help or menu interfaces.

## 2025-05-14 - [Correct Numeric Validation]
**Learning:** Using 'isNaN(parseInt(...))' is essential for reliable input validation feedback; the '=== NaN' pattern leads to silent failures and poor UX.
**Action:** Audited and corrected numeric validation across multiple modules to ensure consistent error messaging for users.
