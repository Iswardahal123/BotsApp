## 2025-05-15 - [Help Menu Alphabetical Sorting]
**Learning:** Organizing command lists alphabetically significantly improves discoverability and scanning for users in a CLI-like environment (WhatsApp bot).
**Action:** Always sort dynamic lists of commands or options by name by default to reduce user cognitive load.

## 2025-05-15 - [Total Command Overview]
**Learning:** Providing a summary count of available features (Total Commands) in a help header gives users an immediate sense of the tool's scale and capability.
**Action:** Include high-level statistics in menus to provide context for the interface's depth.
