## 2025-05-15 - [Enhanced help menu UX]
**Learning:** Adding a total command count to the help menu provides users with immediate context and delight, while alphabetical sorting significantly improves scannability in long lists. Standardizing error messages and trigger formatting further enhances UI consistency and professionalism.
**Action:** Always consider adding summary metadata (like counts) and logical sorting (like alphabetical) to any list-based UI components to improve the overall user experience.
