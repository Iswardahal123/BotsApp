## 2025-05-14 - Scannability and Scale Feedback
**Learning:** In chat-based interfaces where visual search is the primary mode of navigation, alphabetical sorting of command lists significantly improves scannability. Additionally, providing a total command count in help headers offers immediate, valuable feedback on the bot's scale and capability.
**Action:** Always implement alphabetical sorting for command lists and include summary metrics (like total counts) in help menus to improve user orientation.
