## 2025-05-14 - Sorting and Counting for Discoverability
**Learning:** Large command lists without sorting make it significantly harder for users to find specific features, especially in text-heavy interfaces like WhatsApp bots. Providing a total count gives users an immediate sense of the bot's capabilities.
**Action:** Always ensure command lists or feature menus are sorted alphabetically (or by logical category) and include a summary count when appropriate.
