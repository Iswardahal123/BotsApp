## 2025-05-14 - [Help Scannability and Dynamic Feedback]
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a total command count and dynamic prefixing ensures the interface feels responsive to configuration changes.
**Action:** Always sort command/feature lists alphabetically and use dynamic placeholders for configurable items like prefixes to maintain UI accuracy.
