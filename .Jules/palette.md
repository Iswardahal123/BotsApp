## 2025-05-14 - Alphabetical Command Sorting in Help Menu
**Learning:** Organizing command lists alphabetically significantly improves the scannability of the interface for users, especially as the number of available modules grows. Users can quickly locate a command by its first letter rather than having to read through a potentially random list.
**Action:** Always ensure that lists of commands or options are sorted alphabetically by default unless there's a specific reason to prioritize by frequency or category.
