## 2025-05-14 - Sorting and Command Count in Help Menu
**Learning:** Organizing command lists alphabetically and providing a total count improves discoverability and gives users a better sense of the bot's capabilities.
**Action:** Always sort dynamic lists in the UI and include summary statistics (like counts) where helpful for context.

## 2025-05-14 - Trigger Formatting in Help Command
**Learning:** Clean, comma-separated lists for command triggers are more readable than pipe-separated strings with excessive whitespace and delimiters.
**Action:** Use standard punctuation (commas, spaces) for list formatting in text-based interfaces to reduce visual noise.
