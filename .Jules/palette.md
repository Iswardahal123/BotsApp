## 2025-05-14 - [Help Menu Scannability]
**Learning:** Alphabetical sorting of command lists significantly improves scannability in chat-based interfaces where visual search is the primary mode of navigation. Providing a total command count in the header offers immediate feedback on the bot's scale and capabilities.
**Action:** Always sort command lists alphabetically and include a summary metric (like total count) in the help header for chat-based command interfaces.
