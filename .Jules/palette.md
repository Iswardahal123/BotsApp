## 2025-05-14 - [Help Menu Scannability and Scale]
**Learning:** In chat-based bot interfaces, alphabetical sorting of command lists significantly improves scannability as users rely on visual search. Providing a total command count in the header offers immediate feedback on the bot's functional scale.
**Action:** Always sort command lists alphabetically and include a 'Total' count in help or index menus for chat bots.
